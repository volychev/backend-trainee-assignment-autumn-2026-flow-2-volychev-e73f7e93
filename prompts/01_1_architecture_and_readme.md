CONTEXT:
Проект: MVP платформы доставки "Авито.Кухня".
Стек: Python 3.13, FastAPI, PostgreSQL, Docker Compose.
Архитектура системы: SOA (Main API + Mock API). 
Архитектура самого Main API: Модульный монолит
Основной сценарий:
- Клиент создает заказ -> Main API сохраняет его в PostgreSQL.
- Main API отправляет вебхук в Mock Restaurant API.
- Mock Restaurant API подтверждает получение и передает статус обратно.
Аутентификация: Отсутствует (доверяем клиентскому заголовку X-User-ID).
Транспорт: Синхронный HTTP / Вебхуки (без Kafka/RabbitMQ).
